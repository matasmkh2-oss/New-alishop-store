# AliShop V9 Unified Catalog

## التغييرات
- تركوازي غامق في الوضع النهاري وفاتح في الوضع الليلي.
- معالجة تباين النصوص والأزرار والحاويات.
- إعادة تصميم حاوية الرصيد.
- إزالة خلفية الشعار والاكتفاء بإطار ناعم.
- تطبيق إطار تركوازي نهارًا وأبيض ليلًا.
- دمج إدارة المنتجات الرقمية ومنتجات السوشل ميديا داخل كتالوج موحد.
- اختيار نوع العنصر عند الإضافة وتغيير الحقول حسب النوع.
- بحث وفلاتر منفصلة لكل نوع.
- معاينة مباشرة للبطاقة أثناء الإضافة أو التعديل.
- عدادات لكل نوع داخل الكتالوج.
