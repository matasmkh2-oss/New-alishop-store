# AliShop Mobile Update

واجهة موبايل كاملة باستخدام HTML/CSS/JavaScript وSupabase.

## التحديث من Termux

ضع الملف ZIP داخل Download ثم، وأنت داخل مجلد المشروع:

```bash
unzip -o ../alishop-mobile-update.zip
git add .
git commit -m "Mobile app interface update"
git push
```

بعد ذلك شغّل `supabase/mobile_update.sql` مرة واحدة داخل SQL Editor.

بعد تفعيل GitHub Pages افتح الرابط من Chrome على أندرويد، ثم من القائمة اختر:
**إضافة إلى الشاشة الرئيسية**.
