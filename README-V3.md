# AliShop V3 Complete

## التحديث من Termux
وأنت داخل مجلد المشروع:

```bash
unzip -o ../alishop-v3-complete.zip
git add .
git commit -m "AliShop V3 complete store update"
git push
```

ثم شغّل داخل Supabase SQL Editor:

`supabase/alishop_v3_complete.sql`

مرة واحدة.
