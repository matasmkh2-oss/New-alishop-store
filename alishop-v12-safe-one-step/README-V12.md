# AliShop V12 Safe One-Step

هذه الحزمة لا تحذف المستخدمين أو الأرصدة أو المنتجات أو الطلبات.

## الرفع بأمر واحد

بعد فك الملف داخل Download:

```bash
bash /storage/emulated/0/Download/alishop-v12-safe-one-step/install-v12.sh
```

السكربت يفحص JavaScript، ينسخ الملفات، ينشئ Commit ويرفع إلى GitHub.

## قاعدة البيانات

شغّل ملفًا واحدًا فقط:

`supabase/alishop_v12_safe_migration.sql`

الملف:
- ينشئ نسخة احتياطية من الجداول المهمة داخل `alishop_backup_v12`.
- يحافظ على البيانات الحالية.
- يصلح تعارض `products_with_stock` بحذف الـ View فقط وإعادة إنشائه.
- لا يحذف أي جدول بيانات أساسي.
- يوحّد إصلاحات الكتالوج والدعم والتنبيهات والمنصات.
- يسجل الإصدار `12.0.0`.

لا تشغّل ملفات SQL القديمة بعد V12.
