# AliShop V7 Social Catalog

## التغييرات
- استبدال جميع تسميات SMM بـ خدمات السوشل ميديا.
- صفحة المنتجات بوابة إلى المنتجات الرقمية وخدمات السوشل ميديا.
- المنتجات الرقمية تدعم أقسامًا رئيسية وفرعية مع صور.
- بطاقات المنتجات صورة كاملة ونص فوق الصورة، والضغط على البطاقة يفتح المنتج.
- طلب خدمات السوشل ميديا بأسلوب المنصات الرسمية: منصة، فئة، خدمة، رابط، كمية، سعر.
- إدارة منصات مسبقة واختيارها عند إضافة الخدمة مع الأيقونة تلقائيًا.
- فصل طلبات المنتجات عن طلبات السوشل ميديا.
- إضافة قسم مستقل لإشعارات طلبات السوشل.
- تحسين شامل لتباين الألوان في الوضعين.
